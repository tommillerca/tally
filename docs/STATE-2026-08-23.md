## The pattern worth carrying forward

The most valuable output today was not features. It was guards found to be lying.

- `wanderer-despawn-audit` threw a TypeError on an empty sample and graded ZERO
  rows while the gate scored the suite as failing (#117).
- `memory-census` clicked `.looks-card`, a class that has not existed for some
  time, with `?.` swallowing the miss. Two rows graded a screen the suite never
  navigated to and reported "0 elements", which reads as a memory ceiling. Those
  numbers were NOT-MEASURED rather than clean (#125).
- Every static lint here reads audits as TEXT, so a file Node REFUSES TO EXECUTE
  graded clean. A peer lost six of twelve pre-registered runs to it. `PARSES` now
  runs `node --check` on all 221 files in 5 seconds (#123).
- Four agents found faults in their OWN audits while doing prove-reds, including
  one mutation that ran green at exit 0 across an entire live suite.

None of these were found by running the tests. Only by trying to break them.

**Two traps that cost real time today, for whoever reads this next:**
1. `cp -R` of a git WORKTREE is NOT isolated. The copy's `.git` is a FILE pointing
   back at the original, so `git checkout <ref> -- path` inside it writes somewhere
   else and your prove-red passes while proving nothing. Mutate the FILE directly,
   then GREP the copy to confirm the mutation landed.
2. If a revert also removes a test SEAM the audit needs to reach the broken state,
   the audit fails for the wrong reason while its real rows pass GREEN. Isolate the
   defect from the harness: disable only the fix, keep the seam.
