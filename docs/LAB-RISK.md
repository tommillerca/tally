## Method and reproducibility

Run `node scripts/lab-risk-model.mjs` from this checkout root. [The executable model](../scripts/lab-risk-model.mjs) was extracted from the JavaScript appendix in [PRIOR-PACE.md](PRIOR-PACE.md). [Full JSONL results](LAB-RISK-RESULTS.jsonl) contain 26 scenario summaries: 13 scenarios per design, each with 20,000 trials, for 520,000 completed runs. These reuse 20,000 player seeds; they are not 520,000 independent players.

The retained method is:

- Mulberry32 hatch seeds `20260908 + imul(index,2654435761)` and lower-recipe streams per species `1234567 + imul(index,2246822519) + imul(speciesIndex+1,1013904223)`, for indices 0 through 19,999. Protected singleton outcomes still advance their measurement stream exactly as before. Guaranteed Midnight never draws an outcome.
- The same imported local `pickRandomPet`, `eggProgress`, `ownedPairs`, shiny chance/art and 8,000-step egg goal. Each hatch draws shiny before species and the art gate. The existing ready welcome egg is retained, with no new starter grants.
- Casual visits Monday/Wednesday/Friday/Sunday at 5,000 effective steps per visit and 1.6 eggs/week. Daily visits every day at 15,500 steps and 5.9 eggs/week. Recurring eggs use the same end-of-day floor-difference schedule and concurrent incubation.
- The same current-cell-preserving selection policy, C1-to-C6 tie breaks, keeper/spare thresholds, immediate outputs and consume-both bookkeeping. These selection preferences do not filter odds. There is no competing salvage/breeding spending in this model.
- Nearest-rank quantiles, index `ceil(N*q)-1`. An incomplete trial throws before 100,000 days and is never censored or counted as completed. Every action checks inventory conservation and preserved cells; every species finishes with exactly one final experiment. Unprotected costs are checked against the protected minimum. Capacity variants retain identical per-species experiment vectors; ample-stock completion equals `ceil(experiments/slots)`.

The only numerical behavior switch is whether the candidate function uses the original collection/stock filter or returns both lower outputs. The unprotected adapter is also checked against the production `labDistribution` across asymmetric stock cases. Protected checks reproduce all six published profile/milestone median/P90 pairs exactly. No strategy, seed, faucet or capacity adjustment was made.

Setup adaptation: the historical appendix asserted that Rose was absent from `MORPHS`. Rose is now present in this checkout, so that assertion and its control message were updated. Its existing 1,000-draw legacy freshness control remains and passes. This setup-only adaptation is disclosed rather than changing source files to recreate an obsolete checkout.

These are model forecasts under fixed schedules, not observed retention or purchase behavior. Real grant variance, inactivity, stock, strategies and competing sinks can change the dates.
